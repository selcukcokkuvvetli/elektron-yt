Place yt-dlp.exe and ffmpeg.exe in this directory for real downloads.
Use `npm run bootstrap:binaries` during development to fetch them automatically.
Pinned versions and SHA256 checksums are defined in app/binaries.json.
Use `npm run check:binaries` to validate installed executables and license files.
The application's embedded Node runtime is used for YouTube EJS; users need no separate Node installation.
